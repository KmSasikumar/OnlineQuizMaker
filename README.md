# Online Quiz Maker

**Author:** K. Sasi Kumar Yadav

A personal JavaScript project — an interactive quiz app that pulls questions from
the Open Trivia DB API. Pick how many questions you want, a category and a
difficulty, and race a per-question countdown timer (with a countdown sound in the
final seconds).

## Features

- Configurable quiz: 5–50 questions, 17 categories, easy / medium / hard
- Per-question timer (10–60 seconds) with progress bar and countdown audio
- Instant answer checking, running score, and a results screen with restart

## Running it

Open `index.html` in a browser — no build step. An internet connection is needed
for the trivia API and the icon font.
